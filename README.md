# Clinical Hours Tracker

A mobile-friendly clinical hours tracker for healthcare workers who need to document work hours and locations for license renewal.

[→ Live Demo](https://hours-tracker-rosy.vercel.app)

## Features

- Log title, employer, employment type, facility, and specialty
- Track shift type, scheduled shift length, and hours worked
- Record whether an assignment is ongoing
- Keep a running total of hours and renewal summary data
- Export hours as CSV for licensing documentation
- Save entries locally in the browser for quick daily use

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Notes

This version is designed as a responsive web app that works well on mobile devices and can be expanded into a native app later if needed.
